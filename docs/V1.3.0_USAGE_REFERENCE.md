# CarbideUi NGCC - V1.3.0 New Components Usage

Usage reference for the components added in V1.3.0. For the existing components see
[COMPONENT_USAGE_REFERENCE.md](COMPONENT_USAGE_REFERENCE.md).

All components are **standalone**, use **signal inputs / outputs / `model()`**, and are
`OnPush`. Import them from the package root:

```typescript
import { NgccTile, NgccStatTile, NgccTag /* ... */ } from '@assistanz/carbideui';
```

| Component | Selector | Purpose |
| --- | --- | --- |
| [Tile](#1-ngcctile) | `ngcc-tile` | Card with header / body / action / footer slots |
| [Stat Tile](#2-ngccstattile) | `ngcc-stat-tile` | KPI value with trend and status accent |
| [Tag](#3-ngcctag) | `ngcc-tag` | Tag / status badge |
| [Progress Bar](#4-ngccprogressbar) | `ngcc-progress-bar` | Usage meter / task progress |
| [Empty State](#5-ngccemptystate) | `ngcc-empty-state` | Icon, title, description, action |
| [Activity Feed](#6-ngccactivityfeed) | `ngcc-activity-feed` | Activity list / timeline |
| [Structured List](#7-ngccstructuredlist) | `ngcc-structured-list` | Read-only data-driven rows |
| [Notification List](#8-ngccnotificationlist) | `ngcc-notification-list` | Notifications for the header panel |
| [Date Range Picker](#9-ngccdaterangepicker) | `ngcc-date-range-picker` | Presets + custom range |
| [Filter Bar](#10-ngccfilterbar) | `ngcc-filter-bar` | Search combobox with filter chips |
| [Overflow Menu](#11-ngccoverflowmenu) | `ngcc-overflow-menu` | Row action (three-dot) menu |

## CONTAINERS & KPIs

### 1. NgccTile

**What it does**: A Carbon tile (card) with optional header, body, action and footer slots.
It can also act as a link or a button.

**When to use**:
- Dashboard cards and grouped content
- Clickable cards that navigate (`href`) or trigger an action (`clickable`)

**Key Features**:
- **Slots**: `[ngccTileHeader]`, default (body), `[ngccTileAction]`, `[ngccTileFooter]`
- **Inputs**: `heading`, `href`, `clickable`, `disabled`, `light`
- **Output**: `activated` (`Event`) - emitted when a link / clickable tile is activated
- Empty header / footer slots collapse automatically

**Example**:
```html
<ngcc-tile heading="Compute">
  <ngcc-overflow-menu ngccTileAction [items]="menu" />
  <p>12 instances running</p>
  <a ngccTileFooter href="/compute">View all</a>
</ngcc-tile>

<!-- whole tile is a link -->
<ngcc-tile heading="Billing" href="/billing">Current month usage</ngcc-tile>

<!-- whole tile is a button -->
<ngcc-tile heading="Add volume" [clickable]="true" (activated)="addVolume()" />
```

### 2. NgccStatTile

**What it does**: A KPI tile showing a label, a value, an optional delta with a trend arrow and a
status accent bar.

**When to use**:
- Dashboard summary numbers (revenue, instances, error rate)
- Showing change versus a previous period

**Key Features**:
- **Inputs**: `label` (required), `value` (required), `unit`, `delta`, `deltaCaption`
- **Trend**: derived from the sign of a numeric `delta`, or set explicitly with `trend` (`up` / `down` / `flat`)
- **`trendSentiment`**: `positive-up` (default, rising is good), `positive-down` (rising is bad, e.g. cost or errors), `neutral`
- **`status`**: `none` / `success` / `warning` / `error` / `info` - colors the accent bar

**Example**:
```html
<ngcc-stat-tile label="Monthly revenue" [value]="'$48,200'" [delta]="12.5" deltaCaption="vs last month" status="success" />

<!-- a rising error rate is bad -->
<ngcc-stat-tile label="Error rate" [value]="2.1" unit="%" [delta]="0.4" trendSentiment="positive-down" status="warning" />
```

## STATUS & PROGRESS

### 3. NgccTag

**What it does**: A Carbon tag, also used as a status badge (with a leading dot).

**When to use**:
- Status of a resource (Running, Failed, Stopped)
- Categories / labels, and filter chips (dismissible)

**Key Features**:
- **Types**: `red`, `magenta`, `purple`, `blue`, `cyan`, `teal`, `green`, `gray`, `cool-gray`, `warm-gray`, `high-contrast`, `outline`
- **Sizes**: `sm`, `md`, `lg`
- **`dot`**: leading status dot
- **`dismissible`** + `dismissLabel`: close button, emits `dismissed`
- **`disabled`**
- **`NGCC_STATUS_TAG`**: map of status -> tag type (`running`, `success`, `pending`, `warning`, `error`, `stopped`, `unknown`)

**Example**:
```html
<ngcc-tag [type]="NGCC_STATUS_TAG.running" [dot]="true">Running</ngcc-tag>
<ngcc-tag type="blue" [dismissible]="true" (dismissed)="remove()">Region: US East</ngcc-tag>
```
```typescript
import { NGCC_STATUS_TAG } from '@assistanz/carbideui';
readonly NGCC_STATUS_TAG = NGCC_STATUS_TAG;
```

---

### 4. NgccProgressBar

**What it does**: A progress / meter bar that changes color as the value crosses thresholds.

**When to use**:
- Usage meters (CPU, disk, quota) - thresholds highlight risk
- Task progress (uploads, provisioning) - `finishAtMax` turns 100% into "finished"

**Key Features**:
- **Inputs**: `value` (required), `max` (100), `label`, `helperText`, `size` (`big` / `small`), `showValue`
- **Thresholds**: `warningThreshold` (75) and `criticalThreshold` (90), in percent of `max`
- **`finishAtMax`**: 100% is shown as finished (success) and the thresholds are ignored

**Example**:
```html
<ngcc-progress-bar label="Disk usage" [value]="82" helperText="82 of 100 GB" />
<ngcc-progress-bar label="Upload" [value]="progress()" [finishAtMax]="true" />
```

## FEEDBACK & LISTS

### 5. NgccEmptyState

**What it does**: Shows an icon, title, description and call to action when there is no data.

**When to use**:
- Empty tables / lists, first-run screens
- "No results" after filtering

**Key Features**:
- **Inputs**: `title` (required), `description`, `icon` (icon registry name), `size` (`sm` / `md` / `lg`)
- **Slots**: `[ngccEmptyIcon]` for a custom illustration, `[ngccEmptyAction]` for buttons / links
- The action area hides itself when nothing is projected

**Example**:
```html
<ngcc-empty-state title="No instances yet" description="Create your first instance to get started." icon="search">
  <ngcc-button ngccEmptyAction label="Create instance" />
</ngcc-empty-state>
```

> **Note:** `ngcc-button` takes its text from the `label` input. Content placed between its
> tags is not projected.

---

### 6. NgccActivityFeed

**What it does**: Lists recent activity as a compact feed or a connected timeline.

**When to use**:
- Audit / event history on a resource or dashboard
- Showing steps over time (`timeline`)

**Key Features**:
- **`variant`**: `feed` (divided rows) or `timeline` (connecting vertical line)
- **Item** (`NgccActivityItem`): `id`, `title`, `description`, `timestamp`, `datetime`, `actor`, `status` (`info` / `success` / `warning` / `error` / `neutral`)
- **Inputs**: `items`, `variant`, `ariaLabel`, `emptyText`
- Renders an ordered list; `timestamp` is display text, `datetime` feeds `<time datetime>`

**Example**:
```html
<ngcc-activity-feed variant="timeline" [items]="events" />
```
```typescript
events: NgccActivityItem[] = [
  { id: 1, actor: 'Ann', title: 'deployed vm-web-01', status: 'success', timestamp: '2 min ago' },
  { id: 2, title: 'Backup job failed', description: 'Disk quota exceeded', status: 'error', timestamp: '1 hour ago' },
];
```

### 7. NgccStructuredList

**What it does**: A data-driven Carbon structured list for read-only, key/value style rows.

**When to use**:
- Resource details, small read-only tables
- When you don't need sorting / selection / pagination (use `ngcc-table` for those)

**Key Features**:
- **Inputs**: `columns` (`{ key, header }[]`), `rows`, `condensed`, `ariaLabel`
- Cells are looked up by column `key`; missing values render empty

**Example**:
```html
<ngcc-structured-list [columns]="columns" [rows]="rows" [condensed]="true" />
```
```typescript
columns = [{ key: 'name', header: 'Name' }, { key: 'region', header: 'Region' }];
rows = [{ id: 1, name: 'vm-web-01', region: 'us-east' }];
```

### 8. NgccNotificationList

**What it does**: A notification list sized to fill `ngcc-header-panel`, with an unread count,
"Mark all read", "Clear all" and per-item dismiss.

**When to use**:
- The notifications panel in the UI shell header

**Key Features**:
- **Item** (`NgccNotificationItem`): `id`, `title`, `message`, `timestamp`, `read`, `severity` (`info` / `success` / `warning` / `error`)
- **Inputs**: `items`, `heading`, `emptyText`
- **Outputs**: `itemClicked`, `dismissed`, `markAllRead`, `clear`
- **Stateless**: the parent owns `items` and updates them in response to the outputs
- Unread items show a severity-colored edge and bold title; "Mark all read" is disabled when nothing is unread

**Example**:
```html
<ngcc-header-action ariaLabel="Notifications" iconName="notification" [(active)]="panelOpen" />
<ngcc-header-panel [expanded]="panelOpen" ariaLabel="Notifications">
  <ngcc-notification-list
    [items]="notifications()"
    (itemClicked)="open($event)"
    (dismissed)="dismiss($event)"
    (markAllRead)="markAllRead()"
    (clear)="notifications.set([])"
  />
</ngcc-header-panel>
```
```typescript
markAllRead() {
  this.notifications.update((list) => list.map((n) => ({ ...n, read: true })));
}
dismiss(n: NgccNotificationItem) {
  this.notifications.update((list) => list.filter((x) => x.id !== n.id));
}
```

## FILTERING & ACTIONS

### 9. NgccDateRangePicker

**What it does**: A date-range picker with presets and a custom range.

**When to use**:
- Reports, billing, logs - any "show data for..." filter

**Key Features**:
- **Two-way `[(value)]`**: `{ start: Date | null, end: Date | null, preset: string }`
- **Default presets**: Today, Last 7 days, Last 30 days, This month, Last month, Custom range (`NGCC_DEFAULT_DATE_PRESETS`)
- **Custom presets**: pass `presets` (`{ key, label, range?: (today) => { start, end } }`); a preset with no `range` is the custom one
- **Custom range**: start / end date inputs appear; the model only updates when both dates are set and `end >= start` (an inline error shows otherwise)
- **Other inputs**: `label`, `placeholder`, `disabled`, `minDate`, `maxDate`, `today` (override "today" for tests / SSR)
- **`ngccResolveDatePreset(key, today?, presets?)`**: resolves a preset key to a range, e.g. for the initial value

**Example**:
```html
<ngcc-date-range-picker [(value)]="range" label="Billing period" />
```
```typescript
import { ngccResolveDatePreset, NgccDateRange } from '@assistanz/carbideui';

range: NgccDateRange = ngccResolveDatePreset('last-30-days');
```

### 10. NgccFilterBar

**What it does**: A search input that is also a combobox. Typing narrows `Field: Option`
suggestions; choosing one adds a dismissible chip.

**When to use**:
- Above tables / lists that need free-text search plus faceted filters

**Key Features**:
- **Two-way `[(value)]`**: `{ query: string, filters: Record<fieldKey, string[]> }`
- **`fields`**: `{ key, label, options: { label, value }[] }[]`
- **Other inputs**: `placeholder`, `ariaLabel`, `maxSuggestions` (8)
- **Keyboard**: Arrow Up / Down move through suggestions, Enter adds the highlighted one, Escape closes the list (a second Escape clears the text), Backspace on an empty input removes the last chip
- **"Clear all"** resets the query and all chips
- Already-selected options are removed from the suggestions
- The `query` updates on every keystroke - debounce in the parent for remote search

**Example**:
```html
<ngcc-filter-bar [fields]="fields" [(value)]="filter" placeholder="Search instances" />
```
```typescript
fields: NgccFilterField[] = [
  { key: 'status', label: 'Status', options: [{ label: 'Running', value: 'running' }, { label: 'Stopped', value: 'stopped' }] },
  { key: 'region', label: 'Region', options: [{ label: 'US East', value: 'us-east' }] },
];
filter: NgccFilterBarValue = { query: '', filters: {} };
```

### 11. NgccOverflowMenu

**What it does**: A three-dot menu for row / card actions.

**When to use**:
- Per-row actions in tables and lists (Edit, Clone, Delete)
- Tile actions (`[ngccTileAction]`)

**Key Features**:
- **Item** (`NgccOverflowMenuItem`): `id`, `label`, `danger`, `disabled`, `divider` (separator above)
- **Inputs**: `items`, `ariaLabel`, `align` (`start` / `end`), `size` (`sm` / `md` / `lg`), `orientation` (`vertical` / `horizontal`), `disabled`
- **Output**: `itemSelected` (`NgccOverflowMenuItem`)
- **Not clipped**: the menu is `position: fixed`, so table cells and scroll containers don't cut it off; it flips above the trigger near the bottom of the screen
- **Keyboard**: Enter / Space / Arrow Down open (Arrow Up opens on the last item), Arrow keys / Home / End move, Escape closes and returns focus to the trigger; disabled items are skipped
- Closes on outside click, scroll, resize and Tab
- Give each row's menu a specific `ariaLabel` (e.g. `Actions for vm-web-01`)

**Example**:
```html
@for (vm of vms; track vm.id) {
  <tr>
    <td>{{ vm.name }}</td>
    <td>
      <ngcc-overflow-menu [items]="actions" [ariaLabel]="'Actions for ' + vm.name" (itemSelected)="run($event, vm)" />
    </td>
  </tr>
}
```
```typescript
actions: NgccOverflowMenuItem[] = [
  { id: 'edit', label: 'Edit' },
  { id: 'delete', label: 'Delete', danger: true, divider: true },
];
```

## COMPOSITION EXAMPLE

A resource list page using several of the new components together:

```html
<ngcc-filter-bar [fields]="fields" [(value)]="filter" />
<ngcc-date-range-picker [(value)]="range" />

<div class="stats">
  <ngcc-stat-tile label="Running" [value]="running()" status="success" />
  <ngcc-stat-tile label="Failed" [value]="failed()" trendSentiment="positive-down" status="error" />
</div>

@if (rows().length) {
  <ngcc-structured-list [columns]="columns" [rows]="rows()" />
} @else {
  <ngcc-empty-state title="No instances match" description="Try adjusting your filters." icon="search">
    <ngcc-button ngccEmptyAction label="Clear filters" (click)="filter = { query: '', filters: {} }" />
  </ngcc-empty-state>
}
```
